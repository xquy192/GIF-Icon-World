# Security

GIF Icon World reads GIF files from a world folder or from a file selected in the editor. The reader rejects files larger than 64 MiB, images wider or taller than 4096 pixels, and animations with more than 300 frames.

If a GIF causes a crash or unusually high memory use, report it with a small reproduction file, the Minecraft and mod versions, and the relevant lines from `latest.log`. Do not upload a private world save. Remove personal paths from logs before posting them.

For a suspected security issue, contact the maintainer privately before sharing the file publicly.
